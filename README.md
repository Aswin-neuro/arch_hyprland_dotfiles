# My Arch-Hyprland Setup
- Hyprland with modules
1. The files are sourced from hyprland into 6 modules at $HOME/.config/hypr/hyprland/modules/
  - monitors
  - Inputs
  - environment variables (env)
  - Bindings
  - Environment rules(rules)
  - Animations
_The environment is set to qt6ct_
  - wl for copy paste
  - wofi for dmenu
2. Scripts includes
  - sleep script for timeout - swayidle, sleep.sh
  - Slideshow - execute /hypr/scripts/swww-random.sh
  - Zooming - for window magnification /hypr/scripts/zoom.sh
  - workspace change /hypr/scripts/workspace_action.sh
3. Modules
  - binds -> grim+slurp- screenshotting setup

4. Overall
- Minimal wofi
- Transitions (from )
- mocha themed
